# 日本史対策EX v2.0｜1,182問版

GitHub Pagesでそのまま公開できる、HTML/CSS/JavaScript製の日本史四択サイトです。

## 主な更新

- 旧版641問から、1,182問へ増加（独立設問541問を新規追加）。
- 既存380問の設問文・選択肢・解説のいずれかを変更。
- 特に既存の299問は、機械的に選ばれた誤答を同種の歴史事項へ置換。
- 比較・因果関係・年代整序の発展問題を追加。
- 「発展10問に挑戦」ボタンを追加し、結果後の再挑戦でモードを維持。
- 基礎88問、標準754問、発展340問。18の時代区分。

## 既存サイトを更新する方法

すでに公開している `https://ro030314-eng.github.io/nihonshi-taisaku-ex/` を更新する場合：

1. このZIPを解凍する。
2. `https://github.com/ro030314-eng/nihonshi-taisaku-ex` を開く。
3. **Add file → Upload files** から、中身のファイルをリポジトリの最上位へアップロードする。ZIPそのものではなく、`index.html`、`style.css`、`app.js`、`questions.json` などの**展開後のファイル**をアップロードする。
4. 同じ名前のファイルは新しい版へ更新し、**Commit changes** を押す。
5. GitHub Pagesが有効であれば、公開設定をやり直さずに次のデプロイで更新される。古い表示が残る場合はブラウザを再読み込みする。

`index.html` と `questions.json` は必ずリポジトリ直下に配置してください。

## サイトの機能

- ランダム10問・発展10問・条件指定モード
- 時代、難易度、問題形式、出題数の絞り込み
- 四択解答、解説、結果画面、誤答問題の復習
- PC/スマホ対応。数字キー1〜4で解答、Enterで次へ
- 履歴はブラウザのlocalStorageに保存。旧版の学習履歴キーを維持

## 内容と検証について

JSON形式・正答キー・重複・静的ファイルの検証を完了し、Chromiumで画面操作を検証しました。ブラウザの通信アクセスが制限される環境だったため、画面操作テストではテスト用に問題JSONを注入しました。GitHub Pages上での最終デプロイ・通信確認は利用者環境で実施してください。

**全1,182問の史実・誤答選択肢を外部資料と1件ずつ照合したわけではありません。** 追加問題はオリジナルの問題文であり、出典の逐語的転載ではありません。検証範囲と未確認事項は `AUDIT.md` を参照してください。
